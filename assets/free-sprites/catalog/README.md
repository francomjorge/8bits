# PRISMA verified sprite catalog

This directory is generated only from the exact imported CC0 originals.

- `00_IMPORTED_ORIGINALS_CATALOG.png`: enlarged view of every imported source sheet.
- `01_MIN_EXACT_8X8_CELLS.png`: every nonblank 8x8 cell extracted from Min's native 8x8 sheets.
- `exact-cells/`: exact crops, not redrawn.
- `library.json` / `library.csv`: provenance, source coordinates and hashes.

**Important:** cells intentionally start without semantic names. A name is added only after visual verification against the source. This avoids inventing what a sprite represents.
